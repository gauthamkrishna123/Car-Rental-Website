# DriveEase Car Rental Homepage

A responsive car rental homepage built with HTML5, CSS3, and vanilla JavaScript.

## Features
- Responsive navigation with mobile menu
- Hero section and car search form
- Car cards rendered from an array of objects
- Filter cars by category
- Pickup/return date validation
- Dark mode saved with `localStorage`
- FAQ accordion using native HTML `<details>`
- Testimonials, service benefits, footer, and back-to-top button
- Accessible labels and focus styles

## Run locally
1. Extract the project folder.
2. Open `index.html` in a browser, or use the VS Code Live Server extension.
3. Internet access is required for Google Fonts and the sample Unsplash car images.

## Notes
- Rental prices and customer testimonials are illustrative sample content.
- Search and booking are frontend demonstrations only. No real availability, database, or payment processing is connected.
- Links to the other pages are placeholders for the next stage of the multi-page project.
